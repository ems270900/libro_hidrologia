# Hidrología Aplicada a la Ingeniería Civil

*Fundamentos, análisis estadístico y aplicaciones prácticas*

Ing. Edwin Matarrita Segura. Escuela de Ingeniería Civil, Universidad de Costa Rica.

Libro en línea, escrito en [Quarto](https://quarto.org/) con ejemplos en R, para estudiantes que aprenden hidrología y para profesionales que la consultan.

- Versión web: <https://ems270900.github.io/libro_hidrologia/>

## Renderizar

```bash
quarto render                 # libro completo
quarto render 13-IDF.qmd      # un capítulo
```
